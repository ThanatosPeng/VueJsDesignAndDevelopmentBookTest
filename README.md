# 内核手册 · Vue.js 设计与实现学习检测

一个用于《Vue.js 设计与实现》（霍春阳著）逐章、逐节、逐知识颗粒复习与自测的 Vue 3 应用。

v2 把学习单位从「小节」细化到「知识颗粒」：104 个正文小节被拆成 312 个原子知识点，每道题绑定到具体颗粒，交卷后按颗粒输出不熟悉点。同时增加本地学习数据清空能力。

## 功能

- **18 章知识地图**：按书中六篇组织，每章包含导读、设计问题与逐节知识卡。
- **312 个知识颗粒全部可测**：每个正文小节拆成 3 个原子知识点，每个颗粒至少有一道直接关联题。
- **知识颗粒级自测**：所有颗粒都可以单独练习；宽泛题可关联多个颗粒，专项题只验证一个颗粒。
- **章节测试 / 全书检测**：整章检测覆盖该章全部题目；全书检测随机抽取 30 题。
- **颗粒级诊断**：交卷后按知识颗粒计算正确率。一个题目可以关联多个颗粒，低于 70% 的颗粒会被列进「还不熟悉的知识颗粒」。
- **错题复盘**：每道错题可查看用户答案、正确答案、机制解析、关联知识颗粒与知识卡入口。
- **错题本**：基于每个知识点「最新一次作答」生成；重练答对后自动移出，也可以在回顾解析后手动标记「已回顾」移出，或一键清空全部待复习错题。手动移出不会改变检测记录和真实掌握度，以后再次答错会重新出现。
- **学习记录**：最近检测、总体正确率、已测知识颗粒、章节掌握度与错题数量持久化到 `localStorage`。
- **清空本地数据**：页头「数据」按钮或首页「本地学习数据」卡片可打开确认弹窗，一键移除本应用的检测报告、错题、掌握度与继续学习位置。知识卡和题库本身不会被删除。
- **移动端适配**：桌面、平板和手机均可使用。

## 本地运行

环境：Node.js 18+。

```bash
npm install
npm run dev
```

生产构建与预览：

```bash
npm run build
npm run preview
```

运行题库、知识点映射、判题、诊断、持久化与清空数据测试（当前 25 项）：

```bash
npm test
```

## 学习流程

1. 从首页学习地图进入某一章。
2. 展开小节知识卡，阅读 3 个原子知识颗粒。
3. 可以点击单颗「本点自测」，也可以做「本节自测」或「整章检测」。
4. 交卷后查看报告：分数、知识颗粒状态、不熟悉颗粒和错题解析。
5. 回到薄弱颗粒重读，再使用「再测一次」或「错题重练」。
6. 需要重新开始时，从页头「数据」或首页底部卡片清空本地学习记录。

## 知识结构与统计口径

- 全书：104 个正文小节，每节 3 个知识颗粒，共 **312** 个知识颗粒。
- 题库：**248** 道题，其中 135 道原有综合题、113 道知识颗粒专项题；每道题精确绑定到一个或多个知识颗粒。
- 每个知识颗粒至少有一道直接关联题，全部 312 个颗粒都可以单独检测。
- 小节正确率 = 本次该小节答对题数 / 本次该小节题目数。
- 知识颗粒正确率 = 该颗粒关联题目中答对题数 / 关联题目数（以最新一次作答为准）。
- 正确率 `< 70%` 的知识颗粒会进入薄弱点列表。
- 首页、章节页和错题本使用历次作答中每道题的最新状态统计，因此重练可以改善掌握度。
- 每次交卷都会保存完整报告；未作答题目按错误计入本次得分。

数据仅保存在当前浏览器的 `localStorage` 中，键名为 `vue-design-lab:progress:v1`。清空操作只移除这个应用的数据，不会调用 `localStorage.clear()` 影响同源的其他站点数据。

## 题库与知识颗粒覆盖

| 篇 | 章 | 正文小节 | 知识颗粒 | 题目 |

## 设计说明

视觉上采用纸张、墨水与 Vue 绿的编辑设计语言：首页强调知识地图和学习遥测，章节页让「小节 → 知识颗粒 → 本点自测」形成清晰的阅读层级，检测页进入无导航干扰的专注模式，报告页用深色数据面板突出“诊断”而不是单纯的分数。

题目与知识卡是基于对原书内容的理解重新整理的，不是原文摘录。本项目为非官方学习工具，书籍版权归原作者及出版方所有。
